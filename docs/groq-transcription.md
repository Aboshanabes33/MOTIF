# Groq transcription, open PR only

Default provider: Groq whisper-large-v3, direct main-process HTTPS to the fixed Groq transcription endpoint. Selected for error-sensitive multilingual work per Groq docs, not an independently tested Arabic benchmark. No real key available, no Groq request made, no real Arabic quality claim. Arabic text in tests is a mocked response only.

User enters their key in an in-app password field. Electron safeStorage encrypts before disk write; no plaintext key in configuration, logs, transcripts or MCP. Only hasKey/status returns to renderer. Windows DPAPI protects against other OS users, not all apps running as the same Windows user. Linux basic_text/unknown storage is rejected, no plaintext fallback. Save does not verify the key; Delete removes the encrypted credential. Current Electron45 synchronous safeStorage APIs are used; Electron deprecates these for46, migration needed before upgrading. OS crypto is injected in unit tests, not an actual Windows DPAPI round trip. Renderer holds typed key until submit/close and it crosses the isolated preload/main IPC once, unavoidable for in-app entry. No key input via chat.

Audio disclosure appears in settings, source button, status sidebar, MCP descriptions and native per-job approval, default Cancel. Your Groq account controls tier/billing. App cannot prove the account is free-tier and does not upgrade plans. No automatic retries and no silent provider fallback.429 produces quota/rate error and numeric Retry-After advice,401/403 key/access error,413 size error,5xx/network/timeouts clear failures. No vendor error bodies echoed. Fixed HTTPS endpoint rejects redirects,60-second request timeout,1MiB bounded JSON response with segment schema validation. No remote URL uploads, only extracted local audio. Manual local Whisper fallback retains existing cached large-v3-q5_0 pipeline.

Scope remains first60seconds, clearly labeled, NOT full long-video transcription. FFmpeg extracts10-second16kHz mono PCM chunks(~320KB), max6, each checked under20MiB to stay below documented free-tier25MB. A2GiB source video can be reduced safely without uploading video. Independent nonoverlapping chunks may lose words at boundaries; no overlap reconciliation claim. Timestamps offset back into source. Temporary WAVs removed on success/failure/cancel. Cancellation aborts network requests and kills local extraction; job is not marked succeeded after cancellation. Returned transcript remains uncorrected in project and can feed existing bounded HyperFrames captions. No local model required for Groq; FFmpeg still required. Local-only tasks remain local.

Verification: TypeScript/build and mocked HTTP tests for fixed multipart/model, limits, error sanitizing,429 no retry,invalid payloads,key storage fail-closed/ciphertext/status,deletion,real FFmpeg extraction+mocked Groq offset transcript,cleanup,cancelled-vs-failed persisted job states. Electron UI smoke and screenshot inspected. No Windows execution, real key verification or provider e2e. No release/merge/CI/spend.

Sources checked Nov26,2026:

# Real Brands and capability health, PR scope

Stacked on the onboarding PR. No merge. The desktop Brand form now saves real metadata (name, voice/guidelines, up to eight validated colors) to a versioned brands-v1.json in Electron userData/motif-data. Create/edit/delete/search are wired to runtime-validated IPC and a trusted main-process store. Existing document validation, bounded counts/size, exclusive writer lock, same-directory temporary replacement, unique previous-version backups and native delete confirmation protect ordinary use. Unsupported/corrupt versions reject without overwrite. No original media or legacy Harness data is read/moved.

This is local single-user Brand metadata, not a choice of job database, collaborative storage or a complete backup product. Temporary files/backups have private Unix mode; Windows ACL and malicious ancestor-race protection are not verified. Rename is atomic under normal local filesystem behavior, not a power-loss durability guarantee without fsync. Backup retention/restore UI and stale-lock recovery remain to implement. Never call these production-complete guarantees.

Claude MCP config presence is now explicit and separate from verified executable presence. Known Windows MSIX redirected JSON paths are checked for config discovery, but automatic writing remains disabled for that install variant pending native verification. A config file left after uninstall is not labeled an installed app.

Media checks run a bounded version/help command from actual PATH executables for FFmpeg, FFprobe, Whisper and HyperFrames. No installation/download/model inference/render is implied. In this development environment actual checks succeeded with FFmpeg/FFprobe4.4.2, Whisper help and HyperFrames0.9.88 after supplying their installed directories in PATH. A missing executable fails honestly. Windows npm .cmd wrappers and non-PATH media installations are not supported by these checks yet. No arbitrary command is accepted from renderer/MCP.

Verification: strict TS/build,12 real test groups, Brand create/edit/delete/reopen persistence, backup existence and corrupt-version refusal. Actual isolated Electron smoke creates Brand metadata through real IPC, reloads renderer, verifies the stored Brand and screenshots the actual card. Test-only metadata is placed in a new temporary app profile and never shipped/seeded into user state. Screenshot visually inspected. Earlier stdio/HTTP onboarding regression remains passing.

Not implemented: source import, FFmpeg transformation, Whisper transcription, HyperFrames rendering, durable job history/cancellation, real audio recording, AI provider requests. #111–116 remain open. No fake output/progress or invented production readiness. No CI, deployment, spend, release, external service or merge.

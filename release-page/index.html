Connect Claude / Cursor / Codex via MCP

Open MOTIF → MCP → Add MCP and pick your agent: MOTIF writes itself into that app's own config (backup kept). It ships its whole video-edit stack over MCP, so the agent reads motif://video/skill instead of guessing. Prefer manual? Paste this:

{
  "mcpServers": {
    "motif": {
      "command": "node",
      "args": ["C:\\Program Files\\MOTIF\\resources\\app.asar.unpacked\\mcp\\motif-mcp.mjs"]
    }
  }
}
